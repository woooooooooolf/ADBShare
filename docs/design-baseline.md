# ADBShare 原型基线

2026-10-30。基于用户已确认的局域网调试场景，采用 Tauri 2 + Rust + TypeScript。

- 本机已有 ADB Server 保持原有设备连接，本地与远程可并行访问；不实现独占租约。
- 每组独立 IPv4 监听地址和端口，设备按 serial 分配；远端使用标准 adb 的 -H/-P。
- 来源 IPv4/CIDR 与监听网卡分别配置；默认选择该网卡的子网，可进一步缩小范围。
- 获准设备支持 shell、logcat、sync/push/pull、安装等设备流；服务器全局变更拒绝。
- 首版不代理 forward/reverse 的跨主机端口，不承诺 IDE/投屏、protobuf tracking。
- 运行中配置不可编辑，先停止再修改；删除组自动停止连接、清理规则后再删除配置。
- 关闭窗口结束全部共享并批量清理规则；失败时保留窗口供重试。配置持久化但不自动恢复监听。
- 界面将草稿、保存配置与运行状态分开。断开的已分配设备保留成员关系。
- 单应用 EXE，不内置 adb/WebView2。默认配置放 EXE 同级 data；写失败应明确报错。

后续根据真实操作讨论配置流程、权限表达、托盘和常驻需求；此文件不代表最终产品规格。

## 2026-11-04 迭代

- 无组首页只显示简介与三步使用提示，移除主区域共享组标题、运行数量、刷新按钮和内嵌日志。
- 侧栏的共享组 / 本机设备入口使用相同的图标、文字、右对齐数量结构；共享组数量包括当前尚未保存的草稿。
- 删除组、保存、保存并共享 / 开始共享 / 停止共享集中于同一操作行。新建 / 未保存标签移除。
- 应用规则先保存最新配置；启用组自动应用规则（仅本机模式跳过）；停止组保留规则；移除规则先停止组；删除组停止并清理规则后删除配置。
- 日志从侧栏独立打开，支持全局、组、设备三级浏览。设备启停在日志设备行操作，禁用保留成员与历史并撤销该设备的会话，移出组清除该组内设备历史。
- 只保存有上限的内存记录，数据块预览限制和旧记录淘汰数量显式呈现；按查看范围复制、导出与重置。组配置中的设备禁用列表兼容此前没有此字段的配置。
