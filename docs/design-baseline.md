# ADBShare 原型基线

2026-10-30。基于用户已确认的局域网调试场景，采用 Tauri 2 + Rust + TypeScript。

- 本机已有 ADB Server 保持原有设备连接，本地与远程可并行访问；不实现独占租约。
- 每组独立 IPv4 监听地址和端口，设备按 serial 分配；远端使用标准 adb 的 -H/-P。
- 来源 IPv4/CIDR 与监听网卡分别配置；默认选择该网卡的子网，可进一步缩小范围。
- 获准设备支持 shell、logcat、sync/push/pull、安装等设备流；服务器全局变更拒绝。
- 首版不代理 forward/reverse 的跨主机端口，不承诺 IDE/投屏、protobuf tracking。
- 运行中配置不可编辑，先停止再修改；停止撤销该组的全部连接。
- 关闭窗口结束全部共享。配置持久化但不自动恢复监听。
- 界面将草稿、保存配置与运行状态分开。断开的已分配设备保留成员关系。
- 单应用 EXE，不内置 adb/WebView2。默认配置放 EXE 同级 data；写失败应明确报错。

后续根据真实操作讨论配置流程、权限表达、托盘和常驻需求；此文件不代表最终产品规格。
